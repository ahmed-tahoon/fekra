## Implementation notes

- Exact legacy-copy replacements live in `src/i18n/qa-copy.ts` and are applied to CMS reads. New editorial strings are preserved. The stored CMS copy remains unchanged; editors may replace it normally.
- Missing-route lookups request only a published slug, not page layout/media relationships. A bounded short-lived cache and in-flight deduplication limit repeated lookups. Negative entries last five seconds, so publishing a new slug does not require a deployment. Genuine draft previews retain the existing render path.
- CSP remains compatible with the site's inline scripts/styles. It is enforced but is not a nonce-based strict CSP. Never restore unsafe-eval in production just to accommodate a new third-party script.
- Local QA builds use `NEXT_DIST_DIR=.next-qa-review`, isolated from the ordinary development output. That generated directory is excluded from Git and lint.

- The expanded production browser run initially found one Spanish certification-heading mismatch; it was corrected and the Arabic/Spanish browser checks rerun successfully. DE/FR/ES talent sentences were also checked in rendered HTML.
- Final full rebuild passed. A smoke test of that output confirmed the Spanish/Arabic certification headings and a localized French 404 with enforced CSP (186 ms). Existing CAPTCHA/schema regression checks passed without provider calls or record writes.
- Existing development-only ScrollReveal hydration-class warnings were observed. They are not counted as resolved by this workbook's fixes.
